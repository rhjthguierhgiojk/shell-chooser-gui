# shell-chooser-gui

A simple shell environment switcher for Linux desktops.

It lets you switch between multiple Quickshell-based desktop shells from one terminal menu, with automatic cleanup of the currently running shell.

## Features

- Shell selector menu
- Switch between multiple Quickshell shells
- Automatically stops the currently running shell before starting another
- Supports custom shell launch commands
- Works from an SSH terminal
- Clean terminal interface
- User-local installation
- No root installation required for the selector itself

## Current Shells

The default configuration supports:

- ii / illogical-impulse
- end4-pC
- Serpantinum
- Caelestia

You can modify the launcher to add your own shells.

## Requirements

### Required

- Linux
- Bash
- Wayland session
- Quickshell (`qs`)
- Git

### Hyprland

Hyprland is recommended and currently required for some shell/session functionality.

## Supported Linux Distributions

The installer is designed to work across common Linux distributions, including:

- Arch Linux
- Arch-based distributions
  - EndeavourOS
  - CachyOS
  - Manjaro
  - Garuda Linux
- Debian
- Debian-based distributions
  - Ubuntu
  - Linux Mint
  - Pop!_OS
  - Zorin OS
- Fedora
- openSUSE
- NixOS

Other Linux distributions may also work if the required dependencies are available.

## Installation guide 

```
git clone https://github.com/mrjthguierngjoik/shell-chooser-gui.git && cd shell-chooser-gui && chmod +x install.sh && ./install.sh
```
